# The 9th Website

Nine chambers in a ring. A place, not a page.

No build step, no dependencies, no trackers, no external requests. Hand-written HTML, CSS, and JavaScript. Open `index.html` through any static server and walk in.

- `CANON.md` — the site's internal bible: the glyph grammar, the nine rules, the Cartographer's established facts, the calendar of time-locks, the named mechanics. Read it before changing anything. Extend; never contradict.
- `WAVELOG.md` — museum records of each wave: what was made, why, what it means in the canon, what was verified.
- `data/v1/` — the site's written collections: 40 wishes, 9 letters, 16 facts of scale, the Scattered Leaves fragment sets.
- `api/health.js` — the fleet's one server function (prepared for deployment; this repo is a working repo and is not deployed).
- `LIVE_CHECKLIST.md` — the free-tier and go-live audit.

Working track only. There is no `-live` repo for this site, and none is to be created without the owner's explicit order.
